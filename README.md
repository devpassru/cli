# DevPass CLI Tools

Официальный монорепозиторий CLI-инструментов экосистемы [DevPass](https://devpass.ru).

## Пакеты

| Пакет                               | Описание                                                                                 | Запуск                 |
| ----------------------------------- | ---------------------------------------------------------------------------------------- | ---------------------- |
| [`rundeploy`](./packages/rundeploy) | Деплой статики, SPA, Mini Apps и serverless-функций на [RunDeploy](https://rundeploy.ru) | `npx rundeploy ./dist` |

## Разработка

```bash
bun install
bun run build
bun run check
```
